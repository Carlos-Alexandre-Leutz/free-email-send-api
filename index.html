Por que criamos isso?

Serviços tradicionais não foram feitos para portfólios simples

Se você só quer receber a mensagem que um cliente digitou na aba "Fale Comigo" do seu site, você não precisa de um painel corporativo complexo.

O Modelo Tradicional (SendGrid, AWS SES, Mailgun)

  • Exige cartão de crédito e cadastros demorados com verificação de identidade.
  • Obrigatório configurar registros DNS complexos (TXT, CNAME, SPF, DKIM, DMARC).
  • Planos que cobram mensalidade ou expiram créditos após período de teste.
  • Excesso de burocracia para quem só quer receber 10 e-mails por mês.

A Solução free.email.sender

  • Cadastro em 30 segundos: Cadastre seu e-mail (ex: seuemail@gmail.com).
  • Token Instantâneo: Receba uma chave para usar diretamente nas requisições do seu site.
  • Resposta Direta: Respostas do cliente vão diretamente para o e-mail cadastrado.
  • 100% Gratuito: Feito por dev para dev, sem cobrança oculta.

Documentação Rápida

API Playground & Simulação em Tempo Real

Endpoint único em POST https://api.freeemailsender.com/v1/send

Parâmetros Aceitos

token Obrigatório

Chave secreta gerada após realizar o cadastro gratuito no serviço.

to Obrigatório

E-mail de quem vai receber a mensagem (pode ser o seu próprio e-mail ou do cliente).

subject Obrigatório

Assunto do e-mail (ex: "Novo Contato do Portfólio").

message Obrigatório

Texto da mensagem. Aceita texto puro ou HTML simples (sem tags de imagem <img> por motivos de segurança).

cco Opcional (boolean)

Se true, envia uma Cópia Oculta para o e-mail que você usou no cadastro.

Política Anti-Spam Rigorosa Não é permitido o uso para spam, phishing ou conteúdo impróprio/ilegal. Contas que descumprirem essa regra serão banidas permanentemente sem aviso prévio.

Dúvidas Frequentes


        

          

            
              É realmente 100% gratuito? Há limitações?
              
            
            

              Sim, é totalmente gratuito! Ele foi desenvolvido para cobrir projetos de baixo volume (como portfólios pessoais e formulários de contato). Para evitar abusos e manter o serviço veloz para todos, existe apenas um limite de taxa (rate-limit) por IP.
            

          


          

            
              Como recebo a resposta do meu cliente?
              
            
            

              Quando alguém envia uma mensagem através da sua API com o parâmetro to, ou se responder ao e-mail recebido, a mensagem vai direto para o e-mail que você usou no momento do cadastro do seu Token.
            

          


          

            
              Posso enviar imagens na mensagem em HTML?
              
            
            

              Não. O corpo da mensagem aceita HTML simples (negrito, itálico, parágrafos, links simples), mas tags de imagem (<img>) e anexos pesados são desabilitados para prevenir rastreamento indevido e consumo excessivo de banda.
